# Superstore Sales – Exploratory Data Analysis (EDA) | SWYNEX Technologies

## 📌 Task Overview

This repository contains **Task 2 – Exploratory Data Analysis (EDA)** completed as part of my **Data Analyst Internship at SWYNEX Technologies**.

For this task, I used the **cleaned Superstore Sales dataset** prepared during Task 1. The cleaned data was analyzed using **Microsoft Excel**, mainly with **Pivot Tables and Pivot Charts**, to identify sales trends and useful business insights.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Analysis & Visualization

## 🔍 EDA Performed

The following analyses were performed on the cleaned dataset:

* Category-wise Sales Analysis
* Sub-Category-wise Sales Analysis
* Region-wise Sales Analysis
* Ship Mode-wise Sales Analysis
* Yearly Sales Analysis
* Monthly Sales Analysis
* Region & Category-wise Sales Analysis
* Segment & Category-wise Sales Analysis
* State-wise Sales Analysis
* City-wise Sales Analysis
* Product Name-wise Sales Analysis
* Customer Name-wise Sales Analysis

## 📊 Key Insights

* **Technology** generated the highest sales among the three categories with total sales of **₹8,27,455.87**.
* **West** was the highest-selling region with total sales of **₹7,10,219.68**.
* **Standard Class** generated the highest sales among shipping modes with total sales of **₹13,40,831.31**.
* Total sales across the analyzed dataset were **₹22,61,536.78**.
* Yearly analysis showed the highest sales in **2018**, with total sales of **₹7,22,052.02**.
* Region and category analysis was used to understand how different product categories contributed to sales across regions.
* Segment and category analysis was performed to compare sales performance across **Consumer, Corporate, and Home Office** segments.
